
 1) writing commits:
type(scope): short description

feat(auth): implement JWT authentication
# new authentication feature

fix(auth): correct token expiration logic
# authentication bug fixed

docs: update README installation steps
# documentation improvement

refactor(notes): simplify image validation logic
# code cleanup
# functionality stays the same

style: format code using black
# formatting change only
# no logic change

test(notes): add tests for image upload endpoint
# automated tests added

chore: add pillow dependency for image uploads
# installing library

perf(notes): optimize note query using select_related
# improves database performance

build: add Docker configuration
# project can run inside Docker

ci: add GitHub Actions workflow for tests
# automated tests run on push

feat(notes): add image upload endpoint (#12) or
Closes #4
Fixes #4
Resolves #4

# commit related to issue 12
# GitHub links them automatically

2) to create branch
 git checkout -b feature/note-image-upload

3) switch branch
git checkout main

4) creating branches :
# 1) Branch naming

feature/<feature-name>
# new functionality

fix/<bug-name>
# fixing a bug

test/<feature>
# writing or improving tests

refactor/<module>
# restructuring code without changing behavior

docs/<topic>
# documentation changes

chore/<task>
# maintenance tasks (dependencies, configs)

ci/<task>
# CI/CD pipelines

perf/<feature>
# performance improvements


Examples:

feature/note-image-upload
fix/jwt-expiration
test/note-api
refactor/auth-logic
docs/api-setup
chore/update-dependencies
ci/github-actions-tests
perf/query-optimization
